## 🧭 What I build

**Enterprise agent platforms** — Gemini Enterprise agent development: architecting, governing and deploying production-grade agents at scale.

**Multi-agent orchestration** — autonomous pipelines that carry a product from discovery through build to staging without a human in the inner loop.

**Context engineering** — stable-prefix caching, persistent structured facts, summarization and tool-trimming so long-running agents stay coherent and cheap.

**Agent governance** — policy, audit and guardrail layers that make agentic systems reviewable before they touch production.

**Data platforms** — Cloud SQL, AlloyDB, Spanner and BigQuery as the substrate agents actually run on.
